# VTube Studio ホットキー自動再生ツール

Windows・VTube Studio向けのホットキー押下ユーティリティです。GUI でタイムライン（キー押下 / 一時停止）を編集し、音声再生に同期して自動送信します。音声はローカルファイルを `temp_audio/` にコピーして再生・表示します。
再生を開始すると、自動でVTube Studioのウィンドウを選択し、表情設定が正しく伝わるよう動作します。

## 主な機能
- 音声再生に同期したキー送信
- タイムラインの編集（時間・タイプ・キー）と波形上へのマーカー表示
- バンドル（ZIP）でタイムラインと音声をまとめて保存／読み込み
- 波形表示（WaveSurfer）とタイムライン同期、右クリックでイベント追加モーダル
- 設定モーダル：キー押下時間、スキップ秒数、マスター音量、オートスクロール

## 依存
- Python 3.11 以降（推奨）
- `eel`, `keyboard`, `pygetwindow`, `bottle` など（`requirements.txt` を参照）
- Windows10以降で動作確認済み（ファイルダイアログは PowerShell を使用）

※ リリースにはpython3.12.8の組み込み版を同梱しています。

## 使い方
1) **音声を選択**: 「音声を選択する」→ WaveSurfer に波形が表示されます  
2) **イベント追加**:  
   - 下部入力欄で時刻・タイプ・キーを入れて「追加」  
   - もしくは波形上で右クリックしてモーダルから追加  
3) **再生**: 再生ボタン（Space でも可）で開始。イベント時刻でキー送信／一時停止  
4) **スキップ**: ←/→ ボタンで設定秒数だけ移動（デフォルトは10秒）
5) **保存/読込**: 「バンドル保存／読込」で ZIP にタイムラインと音声をまとめて扱う

## 設定項目
- キー押下時間 (秒): VTS が反応しない場合は長めに
- スキップ時間 (秒): スキップボタンの移動量
- マスター音量: 波形再生音量
- オートスクロール: 再生位置に自動スクロールするか
設定はローカルストレージに保存され、キー押下時間は Python 側にも反映されます。

## バンドル（ZIP）構造
```
archive.zip
  ├─ timeline.json
  └─ <audio file>
```
`timeline.json` 例:
```json
{
  "audio_file": "xxx.mp3",
  "events": [
    {"time": 1.2, "type": "press", "key": "A"},
    {"time": 5.0, "type": "pause"}
  ]
}
```
読み込み時は `audio_file` が無ければ ZIP 内の最初の音声ファイルを利用します。

## 一時ファイル
- 音声ファイルは `temp_audio/` にコピーされます。新しい選択や読込で上書きされます。

## 操作ショートカット
- Space: 再生/一時停止
- Esc: モーダルやローディングのクローズ
- 波形ホイール: ズーム、Shift+ホイール: 横スクロール
